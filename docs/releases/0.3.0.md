# python-substack 0.3.0

Version 0.3.0 gives new users a focused five-minute path from installation to
a safe unpublished Substack draft and publishes the complete documentation on
GitHub Pages.

## Highlights

- Start from a task-oriented documentation index.
- Reach an unpublished draft using one getting-started page.
- Follow tested examples for draft creation, scheduling, publication
  selection, JSON automation, and authentication verification.
- See the existing Markdown source and rendered Substack screenshots in one
  walkthrough.
- Navigate focused CLI, Python SDK, safety, and troubleshooting guides without
  losing any previous documentation path.

No runtime interface changed in this release.

## Announcement copy

python-substack 0.3.0 now has a five-minute guide for turning Markdown into a
safe unpublished Substack draft, plus task-oriented GitHub Pages documentation
for authentication, CLI automation, Python, Markdown, MCP, safety, and
troubleshooting. Install it with `pip install -U python-substack` and start at
https://ma2za.github.io/python-substack/.
