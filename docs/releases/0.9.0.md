# Release 0.9.0

## Added

- Image metadata markers preserve editor image attributes during Markdown
  export and update with `python-substack-image:v1` markers.
- Add `allow_image_replacement=False` and
  `substack drafts update --allow-image-replacement` for explicit image
  replacement authorization.
- Draft updates preserve uniquely matched remote image attributes and require
  explicit authorization for unmatched replacements.

## Fixed

- Prevent unintended replacement of remote images with editor metadata during
  Markdown draft updates.
