# Adoption metrics

Metrics are recorded without adding telemetry to the package.

## 0.2.0 baseline

Baseline date: 2026-07-29

| Metric | Value | Source |
|---|---:|---|
| GitHub stars | 158 | GitHub repository |
| GitHub forks | 28 | GitHub repository |
| Cumulative downloads | Approximately 33.5k | Pepy |
| Rolling 30-day downloads | 12,272 | PyPI Stats |
| 14-day views | 118 | GitHub Insights |
| 14-day unique visitors | 49 | GitHub Insights |
| 14-day clones | 261 | GitHub Insights |
| 14-day unique clones | 140 | GitHub Insights |

Release-time referrers:

| Referrer | Views | Unique visitors |
|---|---:|---:|
| github.com | 61 | 14 |
| Google | 15 | 10 |
| community.n8n.io | 1 | 1 |
| search.brave.com | 1 | 1 |

The rolling 30-day count of 12,272 is the download growth denominator for the
1.0 goal. The corresponding target is at least 36,816 rolling 30-day downloads.
Record it immediately before publishing 0.2.0 using:

```text
https://pypistats.org/api/packages/python-substack/recent
```

Update this page and the local maintainer release record at release time and
approximately 14 days after every release.
